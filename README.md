# 🌐 HTML-CSS Projects

A collection of beginner-friendly and practical projects built using **HTML** and **CSS**.  
This repository showcases different layouts, forms, and UI components to strengthen front-end development skills.

---

## 🚀 Projects Included
- 📚 **Book Inventory App** – Manage and display book records with styled tables.  
- 📝 **Survey Form** – A responsive form design for collecting user input.  
- 🖼️ **Flexbox Photo Gallery** – Image gallery demonstrating CSS Flexbox layout.  
- 📄 **Documentation Page** – A simple documentation-style webpage with styled sections.  

---

## 🛠️ Tech Stack
- **HTML5** – Semantic structure and markup  
- **CSS3** – Styling, Flexbox, and responsive design  

---

🎯 Purpose
This repo is designed to:

Practice HTML & CSS fundamentals

Explore responsive layouts
